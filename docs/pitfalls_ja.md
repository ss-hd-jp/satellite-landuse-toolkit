# 納品前チェックリスト — 査読で必ず突かれる10点

実案件（2026-08）の外部レビューで実際に指摘された内容を汎用化したもの。
**対外資料・事業判断に使う成果物は、出す前に全項目を通す。**

## A. 言葉の正確さ

- [ ] **1. 「◯年末の残存森林」と書いていないか**
  Hansen loss は再生を差し引かない。
  ✗「2025年末の残存 849,905 ha」
  ○「2000年に樹冠率30%超だった画素のうち、2025年までにlossが検出されていない面積 849,905 ha」
  ✗「2000年時点の森林の15.0%が失われた」
  ○「2000年に樹冠率30%超だった区域の15.0%で、2001-2025年にtree-cover lossが検出された」

- [ ] **2. 「森林」「回復」と書いていないか**
  樹冠であって自然林ではない。植林・樹木作物・幼齢二次林を含む。
  ✗「7割が再び森林に回復した」 ○「7割はWorldCover 2021でTree Coverに分類された」

- [ ] **3. 「養殖池」「農地」と断定していないか**
  JRCの新規恒久水域＝池・ダム・河道変化・潮汐を含む。**画像で目視確認した場合のみ**断定する。

## B. 推論の強さ

- [ ] **4. 統計値と土地被覆の乖離を因果に変換していないか**
  収穫面積（フロー・複数回作を含む・年次）と土地被覆（ストック・単年・精度76.7%）は別物。
  ✗「同じ土地が数年周期で森と畑を往復するのが実態である」
  ○「両者の大きな乖離は、複数回作・回転型農業・休閑・傾斜地農業の分類誤差などが
     関与している可能性を示す」

- [ ] **5. 比較の期間と指標が揃っているか**
  ✗「A地区289 ha（2019→2026・S2の裸地）は全体18,415 ha（2023-25・Hansenのloss）の桁が2つ下」
  ○ 同一期間・同一指標で再計算する。倍率は「約64倍」「全体の約1.6%」のように実数で書く。

- [ ] **6. クロス集計の対象期間を書いているか**
  被覆図（例：2021年版）より後のlossは転換先を判定できない。
  「2001-2020年のlossのうち◯%」と期間を明記し、残りが未評価であることを書く。

- [ ] **7. 「主役ではない」「実態である」等の断定を、観測事実の外に置いていないか**
  要旨では「〜を示唆する」まで。断定は数値と一体の段落だけ。
  **観測事実の段落と解釈の段落を物理的に分ける**。

## C. 手法の担保

- [ ] **8. 変化検出は共通有効画素（common valid mask）か**
  2時期で独立に雲マスクして面積を比べると、雲量差がそのまま面積差になる。
  **両日とも有効な画素だけを分母**にし、**有効率（%）を表に1行入れる**。

- [ ] **9. 内部整合はとれているか**
  ゾーン別合計と全体の集計が一致するか必ず検算する。合わない場合は原因（境界データの
  レベル差・ラスタライズ・海岸線）を特定し、**脚注で差分を明示**する。黙って出さない。

- [ ] **10. 閾値・パラメータの感度を示したか**
  森林の定義（樹冠率10/30/50%）、NDVIの閾値、occurrenceの閾値。
  少なくとも1つは代替値で再計算し、「結論が閾値に依存しない」ことを示す。

## D. 出典・権利

- [ ] geoBoundaries は**レベルごとに**出所とライセンスを書いたか（ADM1とADM2で違うことがある）
- [ ] Copernicus の表記は `Contains modified Copernicus Sentinel data [年].`（`processed by ESA` を付けない）
- [ ] Hansen / JRC / Esri / HydroBASINS の正式引用文を入れたか
- [ ] 使ったデータの**版**（v1.13 / v1.5 / v200 / v003）と対象期間を本文に書いたか
- [ ] 版が古いものはないか（Hansen・JRCは毎年更新される。作成日時点の最新を確認）

## E. 機微・公開範囲

- [ ] 機密区分は**章ではなく節・図番号で**指定したか（「第6章は不可」だと6.1まで巻き込む）
- [ ] 対外版は**PDFを別に生成**したか（ページを抜くだけでは本文に数値が残る）
- [ ] 特定の事業者・村落を名指しで批判する構図になっていないか
- [ ] 「合法/違法」を衛星データから断定していないか（区分図があっても許認可の有無は別）
